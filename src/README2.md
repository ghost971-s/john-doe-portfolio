📝 Description du Projet
Ce projet est une application web de type "Portfolio en Ligne" construite avec React et React Router. Il vise à présenter mes compétences de développeur web, mes services, mes réalisations passées (Portfolio) et à fournir un moyen simple de me contacter.

L'application est une Single Page Application (SPA), permettant une navigation fluide entre les différentes sections sans rechargement complet de la page.

Technologies principales : React, React Router.

Outil de construction : Vite (Utilisé pour le développement rapide et la construction optimisée).

Styling : Bootstrap.

⚙️ Prérequis
Avant de commencer, assurez-vous que les éléments suivants sont installés sur votre machine. L'utilisation de Vite nécessite une version récente de Node.

Node.js : Version 18 ou supérieure (obligatoire pour la plupart des projets Vite récents).

npm (Node Package Manager) ou Yarn.

Vous pouvez vérifier vos versions en exécutant les commandes suivantes dans votre terminal :

Bash

node -v
npm -v
🖥️ Instructions d'Installation et de Lancement
Maintenant que nous utilisons Vite, la commande de lancement est standard pour tous les projets basés sur cet outil :

1. Cloner le Dépôt
Ouvrez votre terminal et clonez le dépôt Git :

Bash

git clone https://git-scm.com/book/fr/v2/Les-bases-de-Git-D%C3%A9marrer-un-d%C3%A9p%C3%B4t-Git
cd [Nom du dossier du projet]
2. Installation des Dépendances
Installez tous les paquets nécessaires (y compris react-router-dom) définis dans le fichier package.json :

Bash

npm install
# ou
# yarn install
3. Lancement de l'Application
Démarrez le serveur de développement local. Vite lancera l'application sur un port local (généralement http://localhost:5173).

Bash

npm run dev 
# (Ceci exécute la commande configurée par Vite)
